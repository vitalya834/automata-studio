# FSM Generator

Первый прототип продукта: текстовое описание конечного автомата превращается в
типизированную модель, проходит проверки и отображается как SVG-граф.

## Запуск

```powershell
npm install
npm run dev
```

## Проверка

```powershell
npm test
npm run build
```

Проектная документация находится в Obsidian:
`D:\_Проекты\Second Brain\Second Brain\01 Projects\FSM Generator`.
