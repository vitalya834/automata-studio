# Windows-приложение

Automata Studio доступна как браузерная лаборатория и как настольное приложение
для Windows x64. Desktop-сборка содержит тот же проверенный интерфейс, пакет
Node runner, канонические примеры и схемы.

## Файлы для скачивания

- `Automata-Studio-Setup-<version>-x64.exe` — пошаговый NSIS-установщик для
  текущего пользователя с фирменным оформлением и ярлыками с иконкой Automata
  Studio в меню «Пуск» и на рабочем столе.
- `Automata-Studio-Portable-<version>-x64.exe` — автономный файл, который не
  устанавливает программу.

Сборка v1.3 пока не подписана сертификатом Authenticode. Windows SmartScreen
может показать предупреждение о неизвестном издателе. Перед запуском сверяйте
SHA-256 с GitHub Release. Подпись кода необходима до объявления desktop-канала
стабильным.

## Локальная сборка

Требуются Windows x64, Node.js 24 и npm.

```powershell
npm ci
npm test
npm run desktop:smoke
npm run desktop:dist
```

Команда `npm run desktop:assets` повторно создаёт 24-битные шапку и боковые
панели NSIS из сохранённого Windows-скрипта отрисовки.

Готовые файлы копируются в `artifacts/`. Скрипт использует временный путь только
с ASCII-символами, поэтому NSIS работает и тогда, когда путь к проекту содержит
кириллицу.

## Модель безопасности

- renderer работает в sandbox без Node.js integration;
- context isolation и web security включены;
- запросы разрешений, webview и произвольная навигация запрещены;
- во внешнем браузере открываются только проектные ссылки с разрешённых
  HTTPS-хостов;
- для упакованных веб-ресурсов задан строгий Content Security Policy.

Интерфейс v1.3 выполняет браузерные симуляции и тесты виртуального времени.
Нативный мастер настройки и запуска реальных CLI-, HTTP- и Modbus-адаптеров —
следующий этап desktop-разработки.
