# HTTP/REST-адаптер тестируемой системы

[English](HTTP.md) | [Русский](HTTP.ru.md)

HTTP-адаптер связывает независимые от протокола входы FSM с REST-запросами. Он
подходит для веб-API, микросервисов, игровых серверов, inference endpoint
нейросетей и API управления обучающим конвейером. В тест-плане остаются
бизнес-символы, а URL, заголовки и payload находятся в отдельной конфигурации.

## Запуск

```powershell
npm run cli -- run examples/test-plans/http-ml-classifier.json `
  --adapter http --config examples/adapters/http-ml-classifier.json `
  --html ml-report.html --junit ml-junit.xml
```

`npm run demo:http` поднимает временный локальный игровой сервер и насквозь
проверяет переходы запуска, паузы, продолжения и победы.

## Конфигурация

```json
{
  "baseUrl": "http://127.0.0.1:8080",
  "maxResponseBytes": 1048576,
  "reset": { "method": "POST", "path": "/reset" },
  "inputs": {
    "predict_positive": {
      "method": "POST",
      "path": "/v1/predict",
      "body": { "features": [0.9, 0.8, 0.7] },
      "output": { "kind": "json-pointer", "pointer": "/prediction/label" }
    }
  }
}
```

Доступны селекторы результата `json-pointer`, `text` и `status`. Скаляр JSON
становится символом FSM, а объект или массив — компактной JSON-строкой. Перед
каждым тестовым случаем выполняется необязательная операция reset.

## Границы безопасности

- принимаются только HTTP и HTTPS URL;
- путь операции не может перейти на другой origin;
- перенаправления запрещены;
- данные доступа в URL и транспортные заголовки запрещены;
- стандартный предел ответа — 1 МиБ;
- дедлайн тестового шага передаётся запросу как сигнал отмены.

Токен можно указать в заголовке локальной конфигурации, но файл с секретом нельзя
коммитить. HTTP-адаптер проверяет поведение и контракт ML-сервиса, но сам по себе
не измеряет статистическое качество модели.

## Нейросети и игры

Для ML-систем состояниями могут быть загрузка модели, прогрев, inference,
fallback и deployment; входами — образцы и команды; выходами — метки, статусы и
классы ошибок. Для игр естественными состояниями являются меню, сессия, пауза,
matchmaking, победа и поражение. Runner добавляет дедлайны, воспроизводимые
последовательности, JUnit/HTML-отчёты и exit code для CI.

Команда `npm run dataset` создаёт воспроизводимый JSONL-набор переходов для
экспериментов с последовательностными моделями. Это синтетические размеченные
данные от FSM-оракула, а не замена реальным обучающим и проверочным данным.
