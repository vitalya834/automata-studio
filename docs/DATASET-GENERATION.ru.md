# Генерация последовательностей FSM для датасетов

[English](DATASET-GENERATION.md) | [Русский](DATASET-GENERATION.ru.md)

Automata Studio преобразует детерминированный автомат Мили в воспроизводимые
JSONL-эпизоды для задач предсказания следующего состояния, выхода и экспериментов
с последовательностными моделями.

```powershell
npm run dataset -- examples/turnstile.fsm turnstile.jsonl 100 20 2026
```

Каждая запись содержит `episode`, `step`, `state`, `input`, `output`, `nextState`
и `terminal`. Seed делает результат повторяемым. Эпизод начинается в начальном
состоянии и заканчивается в финальном/тупиковом состоянии либо по лимиту шагов.

Генератор требует детерминизма, чтобы каждой паре состояние/вход соответствовал
один эталонный результат. Такие трассы полезны для прототипов и расширения
данных, однако реальная оценка ML требует независимо собранной репрезентативной
выборки и метрик предметной области.
